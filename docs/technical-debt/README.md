## 먼저 인정할 것

**이 저장소에는 이미 이 감사보다 정밀한 부채 대장이 있다.**

`docs/icaros-rebuild/15-infra-debt.md` 는
- 2026-08-27 커넥션 고갈 장애를 **측정값과 함께** 기록한다
  (p50/p90/p99/최대, FATAL 건수, 알람 재발화 여부, 표본 1,104개)
- 2026-08-30 공유 RDS 40분 장애를 **왜 알람 6개가 전부 통과했는지**까지 분석한다
- 남은 위험 16건을 소관·다음 액션·변경 시 위험으로 나눠 관리한다
- **"추가 튜닝은 하지 않는다"** 는 결정과 그 기준(60 초과 시 진행)을 명시한다

`src/lib/db/connection.ts:170-184` 는 사후분석을 코드 주석으로 남겼다 —
*"10초를 60초로 올렸다가 프로덕션을 죽였다. 되돌린 값이다."*

**따라서 이 문서는 그 대장을 다시 쓰지 않는다.**
대장을 코드와 대조해 검증하고, **대장이 다루지 않는 영역**만 추가한다.

## 30초 요약

**인증·DB 계층의 코드 품질은 감사 대상 중 최상위다.**
argon2, Origin 허용목록 CSRF, `httpOnly`+`secure`+`sameSite` 쿠키,
IAM DB 인증 + `verify-full` TLS, fail-closed cron 인증.
**이 계층에 개선할 것이 없다.**

문제는 전부 **프로세스**에 있다 — CI 없음, 테스트 없음, 수동 마이그레이션,
그리고 문서로만 그어진 경계.
